
## Install pixi

```
curl -fsSL https://pixi.sh/install.sh | bash
```

## Update pixi
```
pixi self-update
```

## Uninstall pixi

```
rm ~/.pixi/bin/pixi
```

## First steps

```bash
pixi init project_name
```

```bash
cd project_name
```

```bash
pixi add python
```

```bash
pixi run python
pixi run rstudior
```

```bash
pixi update
```

```bash
# Activate env
pixi shell
```
