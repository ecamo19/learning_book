# General aviation overview

## Heading 

Heading is the __direction__ of an aircraft is heading and is expressed as a 3 digit number in a clock-wise direction. 

In this system North is specified as 360 not as 0

## Wind Velocity
Wind speed is measured in knots. One knot is equivalent to one nautical mile per hour

## Units of Measurement for Aeronautics 

+ Elevation: A mountain has an elevation not a height or altitude
+ Altitude: Indicates how high an aircraft is AMSL
